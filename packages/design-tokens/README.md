# @portfolio/design-tokens

The colors and fonts of `apps/web`, as a Tailwind v4 `@theme` in [tokens.css](tokens.css). The values are placeholders until the real look is designed.

Use it in an app stylesheet, after Tailwind:

```css
@import 'tailwindcss';
@import '@portfolio/design-tokens/tokens.css';
```

Each token becomes a utility class: `--color-ink` gives `text-ink`, `bg-ink` and so on.
